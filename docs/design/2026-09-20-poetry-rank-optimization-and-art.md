# 诗词升官 · 玩法优化与美术资产方案（2026-09-20 · v2 修订）

> 分支：feature/poetry-rank（只含诗词升官玩法）。
> v2 修订（同日）：① 人物体系尽可能丰富；② 增加可玩性（玩法层扩充）；③ 官阶逐步解锁（探索欲）；④ 调研游戏吸引要素写入 §6。
> 风格决策已落定：**游戏内形象 = Q 版**（三张样本已验证，全干净无伪汉字），**封面 = 写实史诗风**（v1 保留）。

## 1. 现状小结

- 机制已闭环：布衣 → 11 阶官衔 + 皇帝登极大考（12 阶）；研习（PRACTICE）攒功名 totalExp，科考（EXAM）晋升，目标 = 当前 + 1；功名只增不减；答案永不下发；门禁/结算幂等全在服务端（`rank-service.ts`）。
- 页面已上线：`/play/poetry-rank`，状态机 IDLE / PLAYING / SETTLED + 刷新恢复；浏览器验收 15/15。
- 已知体验短板：身份感弱、功名缺口无行动牵引、路线图 12 节点窄屏太长、擢升无仪式感、对局无"为了什么"。
- 架构约束（不变）：纯逻辑层零依赖、答案永不下发、门禁服务端强制、结算幂等、语料仅公版。

## 2. 人物体系（尽可能丰富）

**风格**：Q 版 2.5 头身、粗描边平涂 + 水墨国风背景、靛蓝底 + 琥珀金点缀（与前端 indigo/amber 主题对齐）。
已验证：Q 版三样本（主角布衣 / 主考官 / 引路先生）全要素命中、无伪汉字/印章/水印、无面部手部崩坏、64px 小图仍可辨；写实版存在卷轴乱码、伪印章、手部"手套化"。
**一致性策略**：Z-Image 无角色一致性机制，靠**固定角色描述句逐字复用**（同一个人物所有 prompt 角色段一字不改，只变换装/道具/背景），re-roll 只换 seed；seed 台账记 `docs/design/art-seeds.md`。

## 3. 玩法优化（UI 层）

- **官途主页**：身份卡（当前阶 Q 版立绘 + 大官衔字 + 副标题）+ 功名条与估算（"还需约 N 局研习" = 缺口 ÷ 最近 3 局平均功名，纯客户端）+ 路线图压缩（已过关收成一行小圆点，重点当前阶 + 前瞻 2 阶，皇帝恒显）+ 双按钮层级（研习主按钮 / 科考金色次按钮，未达标置灰内嵌缺口）+ 最近战绩（得分/正确率 + 已见 N 题）。
- **对话式出题**：轻对话非剧情。一题 = 出题人一句题面气泡 + 4 选项胶囊；答完 = 一句反馈气泡（对/错 + 出处 + 得分）。双人设映射已有 kind：研习=引路先生（松弛）、科考=主考官（正式）、皇帝大考=钦差/主考官强化（"金殿之上，天子亲试"）。时序红线：倒计时只挂题面气泡，反馈气泡在表停之后，速度分不受阅读速度影响。人设文案表放纯逻辑层 `src/lib/games/poetry/persona.ts`（零依赖可单测）。
- **结算**：擢升仪式感（旧 → 新官衔对比，新阶 Q 版立绘放大 + 晋升台词）；失败可操作（"正确率 50%，距 60% 还差 1 题" + 直接重考）；研习结算 = 功名增量滚动 + 功名条增长可视化；皇帝终点 = 全程形象对比（布衣 → 皇帝）。

## 4. 官阶逐步解锁（探索欲）

1. **路线图战争迷雾**：已升 = 彩色 Q 版立绘；当前 = 高亮脉冲；下一阶 = 半剪影 + 官衔虚化（只露称号不露副标题）；再往后 = 黑色剪影 + "？？？"（称号、副标题、道具全隐，只露难度暗示如"二品大员·???"）。玩家始终能看到"下一步是什么轮廓"，但详情要升上去才揭晓。
2. **官阶档案**：每晋升一阶解锁该阶档案卡——架空设定（称号来历、本阶特权、一句典故）。内容全部公版（诗、史、典故），架空文案不宣称真实官制。档案页 = 收集驱动，12 张全收集有"官途全录"成就。
3. **皇帝隐藏终点强化**：未到丞相（rank 9）时路线图**不显示**皇帝节点（不是剪影，是节点消失，路线图以丞相为可见终点）；拜相结算时钦差现身揭晓"登极大考"——把现有 isEmperor 隐藏机制推到极致。
4. **剪影竞猜（小彩蛋）**：IDLE 页可猜"下一官衔是什么"（从称号池选），猜中给少量功名。零风险小互动，强化"探索下一阶"的心理预期。纯客户端 + 服务端只结算功名（复用 settleKey 幂等通道）。

## 5. 可玩性扩充（玩法层）

> 约束内演进：均为诗词升官玩法内的层，不引入新玩法模式；新增机制的判定全部落纯逻辑层（可单测）或服务端（防作弊）。

### 5.1 每日题 DAILY（P1，设计已预留）

每天 1 题（DAILY_COUNT=1 已有）。**日历收集**：7×N 月历格，完成打勾、连成一行点亮一行纹样；连续完成有周奖。每日题是"最小回归单元"（Gamigion：session goal 1–10 分钟）。

### 5.2 成就徽章（P1，metric 优先）

数据依据：首日完成 **metric 类成就**（有意义的行动里程碑）的用户 30 日留存 33.96%，streak 类 25.57%，无成就 20.46%（Trophy 平台 2026-04 数据）——**先做里程碑类，签到类只当调味**。首批徽章（全 metric 型）：
- 初窥门径（首次研习完局）/ 十拿九稳（首次全对）/ 连中三元（单局 3 连对）
- 童生及第（首次晋升）/ 金榜题名（进士）/ 位极人臣（丞相）/ 登极（皇帝）
- 学富五车（已见 100 题）/ 诗词阁主（已见 500 题）
徽章 = 纯逻辑层数据表定义（条件函数 + 文案），服务端判成就、防伪造；主页设"功名簿"入口展示（收集展示面）。

### 5.3 诗词阁（P1，收集系统）

答过的诗句按朝代/作者/grade 分架，每句卡带出处（公版语料自带），点开看原诗全文与作者小传。"永不重题"从机制变成**可见资产**——玩家看到自己的诗阁在变满，是长期目标感（Meta 留存方法论：有意义的进度是回归理由）。皇帝终点解锁"诗阁·全录"纪念框。

### 5.4 题型扩充（P1，引擎纯函数扩展）

现有：猜诗人/猜诗名/上句补下句（选择题）。新增 2 类，扩大出题组合空间、降低单题型疲劳：
- **选字填空**：句中挖一字，从 4 个形近/义近字中选（干扰项从同诗库取，公版权益不变）；
- **朝代配对**：给出 4 句短句，选对其中一句的朝代。
引擎层加题型分发与干扰项生成纯函数（参数注入语料，单测覆盖）。每局题型按官阶加权混合，高阶局多混合题型（心流"有张有驰"：单一题型=驰，混合=张）。

### 5.5 连对热浪（P1，streak 伦理化）

局内连对计数放大视觉（连击 3/5/8 档变色 + 考官表情升级）。**伦理红线**（streak 设计心理学）：只加奖励不做惩罚——断连只停奖励不扣功名（功名本就只增不减，天然合规）；每日题连签提供"补签"宽限（每月 1 次，等价 streak freeze），绝不因一天缺席清零累积。
社交层后置：匿名玩家体系暂不引入好友/排行（需要账号体系），分享卡（新官衔版）作为轻量社交出口放 P2。

### 5.6 提示机制"问同窗"（P2）

每局 1 次：移除 2 个错误选项（剩 3 选 1，**答案下发明细不变，仅减项不泄底**——合规：响应不含 answerIndex）。消耗少量功名，服务端校验并落 AnswerRecord 防重放。让同窗 NPC 有了功能位（不只是闲聊）。

### 5.7 限时事件（P2，运营节奏）

"春日会试""中秋诗会"等：活动期间每日题功名 ×2、限时徽章（仅活动内可得）、内侍开场播报。Meta 方法论：活动 = 核心循环的放大器，限时可获取内容制造回归时刻；节奏 = 预热 → 活动 → 降温期。频率控制在月度级，防止疲劳。

### 5.8 外观（P2，纯装饰）

主角节日/限定服饰（不影响任何数值，Prodigy 原则：cosmetic 永不影响玩法内容），由成就/活动兑换。皇帝龙袍的"金边变体"可做首个示例。

## 6. 吸引力要素对照（调研结论 → 本方案落点）

| 要素 | 依据 | 本方案落点 |
| --- | --- | --- |
| 核心循环：动机→行动→奖励，可变奖励 | Meta/GDC 2026 留存方法论 | 研习=攒功名（可变：速度分×连击）；奖励轮换（徽章/档案/服饰分期上新） |
| 心流：明确目标 + 难度-技能平衡 + 即时反馈；曲线"有张有驰"而非直线 | 心流理论（契克森米哈赖）落地文 | 每局 10 题明确目标；grade 窗口随官阶上移（已实现）；判题即时反馈 + 连击档；研习(驰)/科考(张)/题型混合(张) 交替 |
| 悬崖 + 台地交替：高峰挑战给强成就感，平缓段积累资源 | Meta 方法论 §2.3 | 科考=悬崖，研习=台地——现有结构天然吻合，显性化（结算文案强调"台地→悬崖"节奏） |
| 进度可见 + 短/长期双轨 | Meta §2.3 | 功名条(短) + 路线图 12 阶(长) + 诗阁(收集轨) + 徽章(里程碑轨) |

| Streak 伦理化：宽限、无硬重置、鼓励语气 | Smashing/UXMag streak 设计文 | §5.5 断连不惩罚 + 月历补签宽限；文案用"歇一天，功名还在" |
| 分层钩子：日（streak/quest）+ 季（事件/重置） | Gamigion 9 rules | 每日题(日) + 月度限时事件(季)；"奖励进度而非在线时长" |
| 低摩擦：一键重开、登录即领、1–10 分钟 session | Gamigion §8 | 直接重考一键（已有）；每日题 1 题 60s 可完；功名自动入账不手动领 |
| 首分钟有意义的升级 | Gamigion §3 | 布衣→童生门槛 2000 功名 ≈ 2–3 局，首局后 10 分钟内可达（上线后用真实数据校准） |
| 白帽优先（真实进步/成就），黑帽（损失厌恶）只用作辅助 | Octalysis 教育应用分析 | 学习真实诗词（白帽主体）；功名不惩罚（弱化损失厌恶），收集/里程碑驱动 |
| 收集 + 文化内容 + 事件运营 | 江南百景图案例（城市/人物收集、夏日庆典活动、联名邮票） | 诗阁收集 + 官阶档案 + 月度事件；公版诗词是天然文化 IP |
| 社交回归理由（谨慎，匿名体系限制） | Meta §2.1 | P2 分享卡（新官衔版）；好友/排行等账号体系后再说 |

## 7. 美术资产清单与风格纪律

- **规格**：立绘 896×1152 竖版；表情包 512×512 头像裁切。
- **风格 DNA（Q 版，全 prompt 统一追加）**：`Q版卡通游戏立绘，2.5头身比例，圆脸大眼，可爱呆萌，线条干净，色彩明快，水墨国风背景点缀，深邃靛蓝暗色背景为底调、暖琥珀金为点缀，高清，游戏图标级精致度。`
- **负 prompt 统一**：`写实，真人，文字，汉字，书法，印章，篆刻，落款，签名，水印，logo，低清晰度，模糊，多余的手，人物比例错误`
- **角色模板**（固定句逐字复用）：
  - 主角：`Q版青年书生，黑发束髻以发带系起，圆脸大眼，清秀可爱`
  - 主考官：`Q版中年官员，圆脸，蓄短须，严肃中透着呆萌`
  - 引路先生：`Q版白发白须老儒生，圆脸，和善慈祥，体态圆滚滚`
- **生成参数（已验证 2026-09-20）**：`z_image_turbo_bf16.safetensors`（UNETLoader `weight_dtype:"default"`）+ `qwen_3_4b_fp8_mixed.safetensors`（CLIPLoader type=`qwen_image`）+ `ae.safetensors`（VAE）；KSampler steps=8、cfg=1.0、euler/simple、`denoise:1.0`。896×1152 单张约 40s。
- **纪律**：同批生成同批比对；不一致的换 seed re-roll（模板不动）；seed 台账 `docs/design/art-seeds.md`；命名 `q_hero_rankXX_key.png` / `q_npc_examiner.png` / `q_expr_examiner_happy.png`；定稿入 `public/art/`。
- **封面例外**：封面用写实史诗 DNA（v1 已出）：`中国古风游戏主视觉海报，工笔与厚涂结合的水墨风格，深邃靛蓝冷调 + 暖琥珀金，史诗感，游戏封面级画质`——门面与游戏内 Q 版的反差本身是卖点。
